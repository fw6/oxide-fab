# Reference sheets — prompts for GPT-image

Generate these yourself with GPT-image (ChatGPT image generation, or the
`gpt-image-1` API at 1536×1024, quality high). Save each result in this folder
under the exact name in the heading, as JPEG if your tool allows it.

Order matters: **turnaround first, then attach it to the detail prompt** so the
close-up sheet shows the same tool. The Figma sheets already here were generated
from prompts alone (no image input); these prompts are written for a tool that
takes the turnaround back in.

House rules for every prompt: one image, 3 columns × 2 rows, thin light-grey
dividers, flat neutral mid-grey background, even soft studio light, no text, no
numbers, no labels, no annotations, no logos, no watermark. Photographic,
sharp, physically plausible heavy industrial engineering.
